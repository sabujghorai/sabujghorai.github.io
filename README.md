# Sabuj Ghorai — Creative Portfolio

A cinematic personal portfolio inspired by immersive,
seasonal 3D website experiences.

## Technology

- HTML5
- CSS3
- JavaScript ES Modules
- Three.js
- Web Audio API
- Google Fonts

## Project Structure

- index.html — Portfolio content
- css/style.css — Main styling
- css/animations.css — Motion and effects
- css/responsive.css — Responsive layouts
- js/main.js — Main application
- js/scene.js — Three.js environment
- js/sound.js — Sound effects
- js/animations.js — Scroll animations
- js/cursor.js — Pointer lighting
- js/navigation.js — Navigation

## Setup

Run the website using a local HTTP server.

    python3 -m http.server 3000

Visit:

    http://localhost:3000

## Profile Image

Save your profile photograph as:

    assets/profile.jpg

## Sound

Sound is disabled by default.

The three sound effects are generated using
the browser Web Audio API.
